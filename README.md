# Internship & Job Opportunity Management System

This repository contains the design and development work for my Internship & Job Opportunity Management System project.

## Project Overview

The Internship & Job Opportunity Management System is designed to provide a centralized platform where students can search for internship and job opportunities, apply for suitable positions, and track their application status.

Recruiters can create and manage opportunities, review applications, and update candidate status. Administrators can monitor users and opportunity listings.
